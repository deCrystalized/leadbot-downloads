# LeadChat → Заявка в CRM · 2.8.48

Для партнёра 624 автоматически отмечается «Запрос отзыва» в заявке CRM.
Для 624 отметка обязательна.

Подготовка заявки без Telegram поддерживается при явно настроенном на сервере
режиме CRM. Одно обновление расширения этот режим не включает.

Запуском управляет вкладка LeadChat → Настройки → Лид-бот.
Для оформления в CRM оставьте открытой обычную вкладку «Чаты» с рабочей сессией.

Обновление
1. Замените файлы в прежней папке LeadChat-Mac, не создавая вторую копию расширения.
2. В chrome://extensions нажмите «Перезагрузить» у «LeadChat → Заявка в CRM».
3. Проверьте версию 2.8.48. Рабочие вкладки с черновиками не обновляйте.
4. Откройте LeadChat в новой вкладке. Готовность проверьте в «Настройки → Лид-бот».

Установка не включает авто. Серверная готовность, качество полного разговора, создание и реальное
чтение карточки и завершение по тому же номеру проверяются отдельно.
Проверки с имитацией не доказывают реальную доставку.

Настройки и вход Telegram повторно вводить не нужно. Ключ модели не входит
в архив и не сохраняется в файлах расширения.

При неизвестном результате создания заявки повторная отправка блокируется:
нужна сверка той же операции и фактической карточки. Закрытие возможно только
после подтверждения своей новой заявки и проверки полей/дублей. В явно
настроенном серверном режиме CRM отписка Telegram не требуется; в обычном
режиме её подтверждение сохраняется. Переносы, претензии и уже существующие
заявки передаются сотруднику.

# C194. Причина остановки при открытой заявке

В локальной связке Avito → CRM расширение обнаружило открытую заявку до запроса разрешения на создание. Сервер сохранил причину и освободил место в очереди на создание. В обоих оформлениях вкладки LeadChat появилась надпись «CRM нашла открытую заявку. Создание остановлено.».

В обоих сценариях потеря ответа API смоделирована после записи причины на сервере. После остановки и нового запуска расширение запросило статус исходной операции. В журнале исполнителя сохранилась отметка об отсутствии отправки, а в карточке задания — подтверждённая остановка. Запросов на создание CRM было ноль. Сохранился открытый исходный диалог без нового номера заявки. Telegram не вызывался.

Причина передаётся только Main, объявившему поддержку поля, и только до запроса разрешения. Старый Main получает прежний запрос. Проверки API подтвердили, что после выдачи разрешения результат остаётся неизвестным и исходное место в очереди удерживается до сверки. Панель показывает причину из последней операции текущего диалога и версии передачи, с привязкой к владельцу и автору.

ZIP расширения 2.8.48 содержит 53 сверенных файла. Извлечённый ZIP прошёл 11 сценариев в изолированном Chromium, включая проверку филиала, обязательного «Отзыва» для 624, дублей и потери подтверждения.

Два промежуточных прогона выявили дефекты тестового стенда. Проверка журнала ожидала одну запись вместо двух, а добавленный тест вывел служебный текст в канал обмена сценариями. Исправлены порядок запуска тестов и проверка обеих записей.

Обновление проверено локально. Рабочая установка C180/C165 и приёмка владельцем в LeadChat остаются открытыми.

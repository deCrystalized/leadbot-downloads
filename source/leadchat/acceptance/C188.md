# C188. Параллельное открытие журнала экспорта

Экспортёр при открытии читал текущий курсор и затем записывал его обратно. Второй экземпляр мог затереть продвижение первого либо сохранить состояние, предшествующее отказу защиты. Обе ситуации воспроизведены на двух соединениях с настоящей SQLite и синтетическими диалогами.

C188 создаёт строку состояния только при её отсутствии. При параллельном открытии сохраняется актуальный курсор. Подготовленная запись используется один раз, а при отказе защиты сохраняются её исходные байты и блокировка чтения индекса.

На C187 обе новые регрессии упали по ожидаемой причине. C188 прошёл 98 тестов и 17 вложенных проверок. Новые тесты прошли Ruff и mypy. В модуле экспортёра mypy прошёл, девять прежних замечаний Ruff сохранились. Сетевых обращений в тестах не было.

Исправление проверено изолированно. Рабочий запуск Avito → CRM из вкладки LeadChat ещё требует согласованной установки C180/C165 и проверки рабочего контура. Снимок GitHub от 19 ноября содержит C187.

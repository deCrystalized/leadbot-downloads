# C191. Ядро C190 в локальной связке LeadChat

Сверены ядро C190, 377 файлов API C160, 200 файлов вкладки C180 и ещё 178 сжатых копий из архива выпуска. Все 53 файла расширения совпали с ZIP 2.8.47. Проверка уникальности включена на стенде.

Классическая встроенная вкладка открыла и остановила тестовый запуск. Подписанный обмен между API и ядром провёл повторный ответ через переформулировку и отдельную проверку. В локальную очередь попало одно сообщение от выбранного автора. Повторное обращение к отправке вернуло ту же квитанцию с одним вызовом тестового получателя. На C189 такой же сценарий остановился до постановки сообщения в очередь.

В классическом и новом оформлении прошли по два сценария восстановления CRM. При потере ответа о разрешении на создание в тестовую CRM ушло ноль запросов. При потере подтверждения карточки прошёл один запрос. После нового запуска расширение читало статус исходной операции, сохранился тот же ID. Поля сохранённой карточки, включая «Отзыв» для партнёра 624, совпали. Старое разрешение на создание во всех четырёх случаях получило HTTP 409. Telegram не вызывался.

Прошли пять локальных сценариев. Для ответа и восстановления CRM использованы отдельные синтетические диалоги. Модель, получатель сообщения и CRM были тестовыми. Сетевых обращений за пределы стенда не было. Ruff, форматирование и mypy для изменённого теста прошли.

Согласованная установка C180/C165, включение владельцем и живая проверка Avito → CRM остаются открытыми условиями приёмки.

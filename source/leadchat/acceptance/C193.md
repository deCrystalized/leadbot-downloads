# C193. Открытая заявка остановила создание

В обоих оформлениях LeadChat исходный диалог дошёл до согласованной формы CRM. Поиск по номеру вернул существующую тестовую заявку в статусе «Ожидает». Код расширения 2.8.47 распознал её, остановил создание до запроса разрешения и сообщил об остановке на сервер.

В каждой проверке запросов на запись в CRM было ноль. Исходная карточка осталась без изменений, новый номер заявки к диалогу не привязался. Диалог остался открыт. После остановки и нового запуска из вкладки расширение читало только статус исходной операции. Сервер отдал новый запуск на проверку прежней попытки, сохранив одну исходную запись работы. Telegram не вызывался.

Выявлен пробел в отображении причины. Расширение получило конкретное сообщение о существующей карточке. API сохранил общий код остановки до создания. После нового запуска локальная запись клиента показывала «проверка создания», хотя запись фонового модуля подтверждала отсутствие отправки. Это ограничение диагностики, а проверка запрета повторного создания прошла.

Прошли два сценария с открытой заявкой и семь регрессий ответа, создания и восстановления. Сверены исходные файлы API, вкладки и расширения. Модель, получатель сообщения и CRM были тестовыми. Сетевых обращений за пределы стенда не было. Ruff, mypy, форматирование и синтаксис JavaScript прошли.

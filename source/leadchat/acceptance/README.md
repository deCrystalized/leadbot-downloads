# Локальная приёмка LeadBot

Отчёты C188–C194 фиксируют версии и результаты проверок. Сценарии ядра C188–C190 находятся в корневом каталоге `tests/`. Сценарии полной связки из C194 включают регрессии C191–C193.

Тесты связки рассчитаны на подготовленный стенд с полным приложением LeadChat. Используйте версии из [отчёта C192](C192.md) и синтетические данные. В каталоге стенда `api/` разместите приложение LeadChat с зависимостями и тестовыми фикстурами `test_native_actions_0111.py`, `test_native_runtime_0111.py` и `conftest.py`. Наложите `api/tests/unit/` из этой папки. Поместите исходники расширения в `extension/ext/`, а сборки обоих оформлений в `web/` с путями, заданными в `browser-control.mjs`.

Стенд загружает ядро из соседнего каталога `C190-composed-reply-preflight-local266-v1`, модуль доставки из `C171-exact-worker-c165` и Playwright из `C164-native-leadbot-tab/frontend-classic/node_modules`. Ссылки и пины отражают структуру проверенного стенда. Для прогона из каталога `api/` передайте `C170_ROOT_VERSION=C190` и уникальный `C121_EVIDENCE_REVISION` в окружение и запустите `python -B ../run_local.py -q tests/unit/test_native_pair_C170.py`. Рабочие аккаунты и ключи для этих сценариев не требуются.

В [C194](C194.md) существующая заявка блокирует повторное создание до отправки формы. Причина остановки остаётся видна в LeadChat после перезапуска.

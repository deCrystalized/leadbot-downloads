# Модели мозга: цепочки, цены, пакет GigaChat

Цепочки сейчас — по проекту 2.0 (§3). Окончательные — по замеру качества (пакет B4, §5): таблица ниже заполняется
по итогам `brain/eval/*`, цепочки меняются в `ai.js` (`ЦЕПОЧКИ`) или без правки кода — переменной окружения
`CHAIN_<ОПЕРАЦИЯ>` (например `CHAIN_EXTRACT=GigaChat-2-Pro,yandexgpt-lite`).

| операция | цепочка (по порядку) | max_tokens | срок на цепочку |
|---|---|---|---|
| extract (разбор переписки) | GigaChat-2-Pro → YandexGPT Lite | 600 | 44 с |
| address (голос ИИ; второй — правила, третий — карта) | GigaChat-2 (Lite) → YandexGPT Lite | 300 | 24 с |
| checklist (регламент) | GigaChat-2 → YandexGPT Lite | 400 | 40 с |
| addition (что дописал клиент) | GigaChat-2 → YandexGPT Lite | 200 | 40 с |
| pick (вид работ / услуг) | GigaChat-2 → YandexGPT Lite | 50 | 21 с |
| ahk_chat (помощник AHK; снимок окна — картинкой в Pro/Max, текстом в остальные) | GigaChat-2-Max → GigaChat-2-Pro → YandexGPT Lite | 800 (или меньше — как просит помощник) | 50 с |

YandexGPT Pro — нигде по умолчанию.

## Цены (₽ за 1000 токенов, вход + выход) — `budget.js`, `ЦЕНА`

| модель | цена | когда |
|---|---|---|
| YandexGPT Lite | 0,20 | всегда |
| YandexGPT Pro | 1,20 | только если указать в цепочке |
| GigaChat-2 / Pro / Max в личном пакете | 0 | пока остаток пакета за год ≥ 5% |
| GigaChat-2 / Pro / Max вне пакета | 0,065 / 0,5 / 0,65 | только если владелец купил пакет: `GIGA_PAID=GigaChat-2-Pro,…`; иначе модель пропускается |
| Yandex Vision OCR (снимок окна помощника AHK) | ≈ 0,13 ₽ за снимок | только когда снимок идёт в модель без картинок (YandexGPT, GigaChat Lite) или `kind: "ocr"` |

Пакет физлица (в год): Lite 250 млн, Pro 40 млн, Max 25 млн токенов. Ответ GigaChat «402» — модель пропускается сутки.

## Режимы (лимит владельца 5000 ₽ в месяц на всё)

На ИИ — `LIMIT_RUB` (5000) минус `FIXED_RUB` (150: функции, хранилище, IP). Месяц — календарный по Москве.

| расход | режим | что делает мозг |
|---|---|---|
| < 80% | normal | цепочки как в таблице |
| 80–100% | economy | только пакет GigaChat и YandexGPT Lite; в ИИ — последние 25 строк переписки вместо 40 |
| ≥ 100% | rules | ИИ выключен: разбор, адрес, регламент, «дописал», вид работ — правилами модулей (ответ 402, `ok:true, mode:"rules"`); `ahk_chat` — 402 «ИИ выключен» |

Владелец может включить режим вручную (до конца месяца) и уменьшить лимит на странице `?op=admin`. 5000 ₽ — жёсткий потолок: ни ручной режим, ни «Задать лимит», ни `LIMIT_RUB`/`FIXED_RUB` его не поднимают; при ≥ 100% — rules в любом ручном режиме.

## Кэш

Ответ модели хранится 14 дней (`brain/cache/<sha>.json`, в памяти экземпляра — 500 последних). Ключ — операция, цепочка
и вход; для разбора переписки — сообщения диалога (id + текст) и карточка, без времени запроса: повторная проверка того же
состояния диалога — 0 ₽.

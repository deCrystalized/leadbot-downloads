# LeadBot Avito → CRM

Снимок исходников от 19 ноября 2026 года. Включены изменения ядра по C190 и исправление C194, которое показывает причину остановки при найденной открытой заявке.

| Путь | Содержимое |
| --- | --- |
| `leadbot/brain/` | Ядро с изменениями C185–C190. Индекс истории, журнал экспорта, проверка итоговой формулировки на повтор, справочники и правила. |
| `leadbot/ui/`, `extension-server/` | Отдельная панель LeadBot и сервис расширения. |
| `ext/`, `packages/` | Исходники и собранный ZIP расширения Chrome 2.8.48. |
| `leadchat/backend/` | Модули C160, миграции, маршруты и обработчики LeadBot для основного приложения LeadChat. |
| `leadchat/frontend-classic/`, `leadchat/frontend-new/` | Файлы встроенной вкладки «Настройки → Лид-бот» и её тесты для обеих тем. |
| `leadchat/c180-*.patch`, `leadchat/c165-worker.patch` | Интеграция вкладки и обработчика с исходным релизом LeadChat `avito-connection-feedback-20261118-v1` и базой C160. |
| `leadchat/worker-c165/`, `leadchat/nginx-c180/` | Исходники пакета обновления и инструменты проверки. |

| `leadchat/acceptance/` | Сценарии и отчёты проверки Avito → CRM до C194. |

## Восстановление

1. Скачайте ветку целиком. Для просмотра или установки расширения в тестовом Chrome распакуйте архив в `packages/` и укажите полученную папку с `manifest.json` в режиме разработчика.
2. Используйте `leadbot/config.example.json` для структуры конфигурации. Подставьте параметры своего контура, учётные данные и доступ к допущенным источникам из отдельного закрытого хранилища. Храните конфигурацию вне Git.
3. Для встроенной вкладки возьмите исходный релиз LeadChat, указанный в таблице, и сверьте изменения по патчам. Для C194 примените изменения из `leadchat/c194-duplicate-stop.patch` к API и обоим оформлениям. Соберите обе темы и проверьте зависимости в приложении LeadChat. Серверные модули из `leadchat/backend/` используют зависимости этого приложения.
4. Сначала проверьте связку на изолированной базе. Для Avito → CRM используется запуск из вкладки LeadChat. Параметры рабочего запуска и роль владельца задаются на стороне LeadChat.

Клиентские переписки, базы и индексы рабочей истории, ключи и конфигурации серверов хранятся отдельно. Часть исторических тестов использует эти данные. ZIP расширения собран из `ext/` этого снимка. C194 проверен на локальном стенде с синтетическими диалогами. Для рабочего запуска нужны базовый LeadChat, настройки CRM и доступ к разрешённой истории.

Файлы `style_examples.json` и `rag_examples.json` содержат пустые списки, чтобы можно было запустить тесты после клонирования. Для работы с историей подключите допущенные данные отдельно.
